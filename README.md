# AI Advent Challenge — День 8

GigaChat / DeepSeek Book Lab: агент с переключателем моделей, книгами в контексте, инструментами для работы с документами, точным учётом токенов и проверкой лимита контекста.

## Что нового по сравнению с Днём 7

- Переключатель моделей: **DeepSeek Flash** (по умолчанию) и **GigaChat 2 Lite**.
- Добавлены предустановленные книги и инструменты `list_documents`, `document_stats`, `search_document`, `read_document`.
- Полный текст книги можно добавить в историю контекста одной кнопкой.
- Для каждого ответа показываются точные `prompt_tokens` / `completion_tokens` от GigaChat, размер истории в символах и заполнение контекста.
- Перед запросом считается примерная оценка контекста, но запрос **не блокируется**: при превышении в лог пишется предупреждение, а решение принимает GigaChat.
- GigaChat function calling адаптирован к внутреннему формату агента: `functions`, `function_call`, роль `function`, `functions_state_id`.

## Модель и API

- Модель: `GigaChat-2` (Lite).
- Контекст: **128 000 токенов**.
- Freemium: 250 млн токенов Lite на 12 месяцев, один поток.
- Base URL: `https://api.giga.chat`.
- OAuth: `https://ngw.devices.sberbank.ru:9443/api/v2/oauth`, scope `GIGACHAT_API_PERS`.
- Для TLS используется CA-бандл Минцифры: `certs/russian_trusted_ca_bundle.pem`.

### DeepSeek

- Модель: `deepseek-flash`.
- Base URL: `https://api.deepseek.com`.
- Ключ хранится в `api_key.txt` (скопирован из предыдущего проекта).
- Выбирается в верхней панели; история и инструменты общие для обеих моделей.

## Инструменты

| Инструмент | Аргументы | Что делает |
|---|---|---|
| `get_current_time` | `timezone` (IANA, опционально) | Текущие дата/время, по умолчанию UTC |
| `calculate` | `expression` | Арифметика: `+ - * /`, скобки, десятичные дроби |
| `convert_currency` | `amount`, `from`, `to` | Конвертация RUB / USD / EUR / CNY по фиксированному курсу |
| `list_documents` | — | Список книг: id, название, автор, символы, ≈ токены |
| `document_stats` | `document_id` | Точные символы, слова, абзацы и строки |
| `search_document` | `document_id`, `query`, `limit` | Число вхождений и фрагменты с контекстом |
| `read_document` | `document_id` | Читает и возвращает весь текст документа сразу |

Текст книги не передаётся в аргументах инструментов — сервер читает файл по `document_id`.

## Контекст и токены

- «Добавить в контекст» добавляет полный текст книги в `ChatState.Messages` как user-сообщение и сохраняет карточку в `ChatState.Documents`.
- `historyChars` — размер всей истории в символах.
- `approxHistoryTokens` — оценка по формуле `символы / 3`.
- `requestTokens` / `responseTokens` / `totalTokens` — точные значения из `usage` GigaChat, суммарно по всем вызовам хода (если были tool_calls).
- `cumulativeTokens` — суммарно за сессию.
- `contextPercent` — максимальный `prompt_tokens` среди LLM-вызовов хода относительно 128K.
- Если примерная оценка превышает `CONTEXT_LIMIT`, сервер только пишет предупреждение в лог и отправляет запрос дальше.

## Сценарии

1. **Один инструмент**
   - `Сколько слов в романе «Отцы и дети»?`
   - Ожидаемо: `list_documents` → `document_stats("medium-otcy")`.

2. **Поиск по тексту**
   - `Сколько раз в «Отцах и детях» встречается слово «любовь»?`
   - Ожидаемо: `search_document("medium-otcy", "любовь")`.

3. **Два инструмента + калькулятор**
   - `Сравни «Войну и мир» и «Анну Каренину» по числу символов и токенов.`
   - Ожидаемо: два `document_stats` и `calculate`.

4. **Анализ книги по тексту**
   - `Проанализируй книгу «Отцы и дети», какова тема романа?`
   - Ожидаемо: `read_document("medium-otcy")` — инструмент возвращает весь текст сразу.
   - Модель не должна отвечать по общим знаниям, если текст не был прочитан.

5. **Книга в контексте**
   - Добавить `medium-otcy`, затем спросить: `Кто такой Базаров и как он относится к искусству?`
   - Модель отвечает по полному тексту, без инструментов.

6. **Переполнение контекста**
   - Нажать «Сценарий: 100K + 200K + 300K» или добавить `book-100k`, `book-200k`, `book-300k`.
   - Суммарно это `≈600K` токенов; запрос всё равно уйдёт в GigaChat — смотри, что он ответит: ошибку контекста или ответ.
   - Быстрый вариант — добавить `war-and-peace` (~800K) или `anna-karenina` (~500K).

## Запуск

1. Получите Authorization Key в личном кабинете GigaChat API.
2. Запишите его в `gigachat_auth.txt`:

   ```
   <authorization-key>
   ```

3. Запустите:

   ```powershell
   go run .
   ```

4. Откройте http://localhost:8087

## Интерфейс

- В верхней панели — переключатель модели; выбранная модель сохраняется в localStorage.
- Слева — список книг с кнопкой «+ в контекст», сценарий переполнения, статистика контекста, каталог инструментов и проверочные запросы.
- Справа — только чат: сообщения пользователя и ответы агента, без показа запросов к LLM и tool_calls.
- У каждого хода — модель, токены входа/выхода, размер истории, процент контекста и время.
- «Сбросить контекст» очищает историю, `turns` и добавленные документы.

- Системный промпт не сохраняется и добавляется заново.
